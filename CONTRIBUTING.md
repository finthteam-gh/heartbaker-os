# Contributing

## Adding or changing material

1. Find the right section in `docs/README.md`.
2. Read the neighbouring documents so you do not repeat what they already say.
3. Make the change on a branch. Name it for the work, for example `brand/voice-guidelines`.
4. Update `docs/README.md` if you add a document.
5. Add a line to `docs/decision-log.md` if the change settles something.

## Style

- British English, sentence case headings, no em dashes.
- FINTH is always written in capitals.
- State each point once, in the place that owns it, and link to it elsewhere.

## Commits

- Write the subject line in the imperative, for example "Add voice guidelines".
- Keep each commit to one piece of work.

## Review

Brand and content changes need sign-off from the named approvers once they are recorded in `README.md`.
