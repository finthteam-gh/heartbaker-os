# Tools

Small tools that support the Heartbaker workflows. Each tool has its own folder and README.

## Filing logic

| Tool | Folder | Purpose | Status |
| --- | --- | --- | --- |
| Post Maker | `post-maker/` | Adds the real logo and brand fonts to ChatGPT images and exports every size | Prototype v0.1, tested on synthetic photos only |

Brand files stay in `docs/brand/assets/`. Tools read them from there and never keep a second copy.
