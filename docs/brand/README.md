# Brand

Home for Heartbaker brand material. Each settled element lives on one page here and other pages link to it. Jere approves all brand decisions.

## Filing logic

| Element | File | Status |
| --- | --- | --- |
| Positioning, range, prices and audience | `positioning.md` | Facts recorded, statement to be written |
| Identity: typography, finishes, label | `identity.md` | Recorded |
| Voice and tone | `voice.md` | To be written |
| Approved wording | `wording.md` | To be written |

Create each remaining file when its content is ready, and change its status here.
