# Identity

Source: brand decisions on file, supplied by Jere on 20 Oct 2026. Jere approves any change. Items marked "proposed" await his approval.

## Typography

- Amsterdam Three (script) is reserved for "The Aperitif Collection". The Post Maker applies this rule itself, using the artwork in `assets/` (decision of 20 Oct 2026).
- Flavour names are set in Quicksand.
- Thai text is set in Sarabun (decision of 20 Oct 2026). Quicksand has no Thai letters, and Sarabun covers Thai and Latin.
- English text on posts: font to confirm from Brand OS. Quicksand stands in.

## Finishes

No gold foil.

An AI image generator must never draw the logo. It redraws the facets and proportions each time. Place the file instead.

## Label

- Label elements stay centred, unless breaking that is creative and tasteful.
- The approved 45 g label style is RAW botanical, with a centred vertical panel, one per flavour.
