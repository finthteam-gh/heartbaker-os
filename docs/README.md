# Documentation index

Each section has a purpose. File new material in the section it serves.

| Section | Purpose | Status |
| --- | --- | --- |
| `brand/` | Positioning, identity, voice and approved wording | Positioning and identity recorded |
| `commercial/` | Sales channels and campaign plans | Recorded |
| `workflows/` | Step-by-step workflows, with who does what | Social post workflow drafted |
| `brand/facts.md` | Facts that go on posts, with their confirmation status | Drafted, items to confirm |
| `decision-log.md` | Dated record of settled decisions | Started |

## Adding a section

If no section fits a new kind of work, create the section, write its filing logic in its own `README.md`, then file the work inside it. Add the section to the table above.
